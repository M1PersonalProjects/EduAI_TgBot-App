# Руководство пользователя EduAI

## 1. Вход и регистрация

Основная регистрация выполняется через Telegram-бота EduAI. После регистрации WebApp может авторизовать пользователя через Telegram WebApp. В обычном браузере доступен вход по Telegram ID для существующей учётной записи.

## 2. Роли

### Ученик

Ученик работает с AI-тьютором, выполняет задания Учителя и собственную AI-практику, открывает интерактивные упражнения, использует учебники и следит за XP, серией и достижениями.

### Учитель

Учитель управляет связанными Учениками, создаёт и генерирует задания, прикладывает материалы, получает результаты, использует AI-помощника и аналитику. В технической модели проекта роль Учителя хранится как `parent` — это внутренняя деталь и не меняет название роли в интерфейсе.

### Администратор

Администратор управляет учебниками, страницами, оцифровкой, пользователями и журналом активности. Администратор также может использовать преподавательский режим там, где это предусмотрено API.

## 3. AI-тьютор

1. Откройте раздел **ИИ-тьютор**.
2. Выберите существующий чат или создайте новый.
3. Напишите вопрос или прикрепите учебный файл.
4. Для работы по конкретному учебнику активируйте Book Mode.
5. Ответы поддерживают Markdown и математические формулы.

Список чатов можно сворачивать. На мобильном устройстве он открывается как drawer. Кнопка перехода вниз появляется, когда пользователь находится выше последних сообщений.

## 4. Book Mode

Book Mode закрепляет учебник/страницу/параграф как основной учебный контекст. EduAI сначала использует выбранный материал, а при недостатке информации может добавить релевантный контекст из других материалов или внешних источников. Выход из Book Mode возвращает чат к общему контексту.

## 5. Файлы

В чатах и заданиях можно использовать поддерживаемые вложения. Система проверяет владельца файла и не должна давать одному пользователю доступ к чужому вложению. В заданиях Учитель отдельно выбирает, использовать ли файл как AI-контекст и показывать ли его Ученику.

## 6. Задания Учителя

Учитель может:

1. выбрать одного или несколько Учеников;
2. указать предмет/тему;
3. написать задание вручную или попросить AI сгенерировать его;
4. добавить публичный комментарий;
5. добавить приватные AI instructions;
6. приложить материалы;
7. проверить preview и отправить задание.

Приватные инструкции и эталонный ответ не должны отображаться Ученику.

## 7. Выполнение заданий

Ученик открывает назначенное задание, отправляет ответ и получает понятный feedback. Для многошагового задания система сохраняет прогресс по вопросам. Награда начисляется после завершения с учётом сложности, качества и повторяемости темы.

## 8. AI-практика

Ученик может запускать самостоятельную практику. Такие задания отделены от заданий Учителя (`tutor_practice` против `teacher`) и не должны попадать в преподавательскую статистику как назначенные Учителем.

## 9. Интерактивные приложения

EduAI умеет создавать интерактивные образовательные приложения. Они открываются в sandboxed iframe. Учитель может получить приватный ключ ответов, а проверка ответов выполняется сервером, чтобы эталон не попадал в браузер Ученика.

## 10. Telegram

Telegram поддерживает основные учебные сценарии: AI-чат, учебники/Book Mode, задания и профиль. WebApp предоставляет более полный интерфейс и историю.

## 11. Прогресс и геймификация

В кабинете Ученика доступны XP, монеты, серия занятий, достижения и цели. Повторные однотипные действия защищены от бесконечного фарма через idempotent event ledger и коэффициенты повторения.

## 12. Если что-то не работает

- обновите страницу и повторите действие;
- проверьте подключение к интернету;
- для Telegram WebApp откройте приложение заново из бота;
- если AI временно недоступен, повторите запрос позже;
- при проблеме с конкретным файлом попробуйте другой экспорт PDF/DOCX или уменьшите размер файла;
- не отправляйте администраторам API keys, пароли или токены в сообщениях.

## Настройка интерфейса

В верхней панели доступна кнопка ⚙. В ней можно выбрать тему **Светлая / Тёмная / Система**. Режим «Система» следует настройке устройства, а выбор сохраняется между открытиями приложения.

На телефоне основные разделы находятся в нижней navigation bar, остальные доступны через «Ещё». В AI Tutor список чатов и Book Mode открываются отдельными панелями и не уменьшают постоянную ширину чата. На desktop/tablet отдельные dashboard-модули можно менять местами перетаскиванием; команда «Сбросить расположение» возвращает стандартный порядок.

Плавающая кнопка `↓/↑` появляется только после прокрутки и ведёт к противоположному краю текущей области прокрутки.
